# 00-Inbox

Área de captura rápida. Notas soltas, ideias e rascunhos entram aqui primeiro — sem se preocupar em organizar de imediato.

Depois, cada nota deve ser revisada e movida para a pasta temática correspondente: `Referencias/`, `Sabores/`, `Manuais/`, `Sem-alcool/` ou `Projeto-Vale-Verde/` (use `git mv` para preservar histórico). Adicione as tags relevantes (ver [[Tags]]) e uma seção "Ver também" antes de mover. Veja [[Home]] para os links das notas já organizadas em cada área.
