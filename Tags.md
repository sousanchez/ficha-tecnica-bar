# Tags

Dicionário de taxonomia do vault — tags em uso e quando usar cada uma.

| Tag | Quando usar |
|-----|-------------|
| `referencia` | Nota sobre um livro/fonte de referência de coquetelaria (ex.: `Referencias/`) |
| `coqueteis` | Conteúdo diretamente relacionado a coquetéis/drinks |
| `sabores` | Nota sobre teoria/catálogo de sabores e harmonização (ex.: `Sabores/`) |
| `foodpairing` | Especificamente sobre a técnica/ciência de foodpairing |
| `treinamento` | Material de formação e capacitação de equipe de bar |
| `manual-bar` | Manual operacional de bar (cultura, processo, produto) — ver `Manuais/` |
| `receitas` | Nota que reúne múltiplas receitas ou fichas técnicas |
| `sem-alcool` | Coquetelaria e bebidas sem álcool — ver `Sem-alcool/` |
| `projeto` | Nota ligada a um projeto específico (ex.: retrofit Florest) |
| `vale-verde` | Conteúdo do Grupo/Projeto Vale Verde Festas e Eventos — ver `Projeto-Vale-Verde/` |
| `cardapio` | Cardápio de evento ou casa |
| `receita` | Ficha técnica de um coquetel/drink específico |
| `indice` | Nota de índice/dashboard (ex.: Home, LIVROS, Tags) |
| `biblioteca` | Nota que cataloga ou resume a biblioteca de referência |
