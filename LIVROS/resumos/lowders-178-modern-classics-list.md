# Lowder's Easy List of 178 (Modern) Classics to Know

**Source file:** `LowdersEasyListof178ModernClassicsToKnow.xlsx` (single sheet: "Modern Classics", 208 rows, 5 columns)

## Structural overview

A flat, spreadsheet-format cocktail database with exactly **178 named cocktails**, organized under **30 category headers** (in column A, present only on each category's first row). Columns are:

| Column | Content |
|---|---|
| A — CATEGORY | Spirit + technique grouping (e.g. "Gin Shaken", "Rye Stirred", "TIKI"), populated only on the first row of each group |
| B — COCKTAIL NAME | Drink name |
| C — INGREDIENTS OZ | Full ingredient list in US fluid ounces, lettered a/b/c… |
| D — INGREDIENTS ML | Same ingredient list converted to milliliters |
| E — METHOD | Build technique / glass / ice / garnish, condensed into a single slash-separated line |

This is the spreadsheet counterpart to `LowderClassicRecipeTrainingManual.pdf` (2016, Chris Lowder / Indie Bartender) — same author, same title, same underlying recipe set (the PDF's "6-per-spirit core list" + its "102 More Drinks Everyone Should Know" appendix add up to exactly these 178 rows). The xlsx strips out all of the PDF's teaching prose/philosophy and keeps only the pure data table, in a format bartenders can filter/print/laminate directly, with both oz and ml columns for international use.

**Data quality note:** the source file has minor mojibake in curly apostrophes/accents (e.g. "Poet's Dream" renders as "Poet�s Dream", "Piña Colada" as "Pi�a Colada") — cosmetic only, does not affect ingredient or method data.

## Data format detail (per recipe)

Every recipe row follows the same schema, e.g. for **Corpse Reviver No. 2**:
- Ingredients (oz): .75 oz. London Dry Gin / .75 oz. Cointreau / .75 oz. Cocchi Americano / .75 oz. Fresh Lemon
- Ingredients (ml): 25ml London Dry Gin / 25ml Cointreau / 25ml Cocchi Americano / 25ml Fresh Lemon
- Method: "Shake/fine strain/absinthe-rinsed coupe/no garnish"

The Method column consistently encodes, in fixed order: mixing technique (shake/stir/build/swizzle/muddle), straining, glassware, ice type, and garnish — enabling the sheet to be read as a compact recipe card for each of the 178 drinks without needing prose explanation.

## Practical use

This file functions as the pure "answer key" recipe database referenced by the training manual — suited for printing as a laminated bar reference, importing into a POS/recipe app, or filtering by category/spirit for staff study sheets, since it carries no narrative content, only structured ingredient and build data for all 178 drinks.
